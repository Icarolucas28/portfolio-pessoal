# Portfólio pessoal - Ícaro Lucas

Portfólio one-page desenvolvido com Next.js, TypeScript, Tailwind CSS, Framer Motion e Lucide React.

## Executar localmente

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
npm start
```

Os dados pessoais e acadêmicos podem ser atualizados em `src/data/portfolio.ts`.
